冲煮

计时开始后，称重页切换到大字的专注视图，隐藏导航和设置；计时复位后自动恢复。 任何时候双击屏幕镜像也可以手动进入。

关于

通过 Web 蓝牙连接，需要 Chrome 或 Edge；Linux 需开启 chrome://flags/#enable-experimental-web-platform-features。 授权过的秤会自动重连。冲煮计时开始时自动录制，暂停计时同时暂停录制，复位计时后保存； 称重页的"注水自动计时"开启时，检测到持续注水会自动开始计时。
快捷键：T 去皮，L 计时，M 切换模式。
