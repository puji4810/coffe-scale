通过 Web 蓝牙连接，需要 Chrome 或 Edge；Linux 需开启 chrome://flags/#enable-experimental-web-platform-features。 授权过的秤会自动重连。冲煮计时开始时自动录制，暂停计时同时暂停录制，复位计时后保存。
