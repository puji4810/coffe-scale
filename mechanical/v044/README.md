# v0.4.4：平顶外壳，显示玻璃嵌平，仅秤盘凸起

按 v0.3 的外形关系重新安排固定壳体：**前方显示玻璃嵌入壳体，四周外露塑料顶边与玻璃共面；取消独立长条显示台座，只有活动秤盘高出壳体。** 保留 LC7012、双 TTP223 以及 v0.4.2 的垫片、定位销和可锁紧限位。

![平顶外壳](../exports/v044/overview.png)

## 外形和高度

| 项目 | 本版默认值 |
|---|---:|
| 外形长宽 | 160×140 mm |
| 外露塑料顶边 Z | 30.0 mm |
| 前玻璃顶面 Z | 30.0 mm，与塑料顶边齐平 |
| 固定壳体顶面距地面 | 34.0 mm，地面 Z=-4 |
| 活动秤盘顶面距地面 | 43.8 mm |
| 秤盘高出壳体 | 9.8 mm |
| 前玻璃 | 154×34×1.1 mm，整片无孔 |
| 玻璃装配槽 | 154.6×34.6 mm，名义单边间隙 0.3 mm |
| 玻璃底胶 | 0.2 mm，固定侧周边胶框 |

玻璃座底 Z=28.7，胶 Z=28.7..28.9，玻璃 Z=28.9..30.0。显示窗是玻璃背面的透明油墨区，不是玻璃孔洞。两块触摸板仍贴在固定玻璃背面，固定胶不能跨接活动秤盘。

外围侧壁统一到 Z=30.0；前部玻璃座与外壁融合后按整机圆角轮廓裁切，取消前面凸出的长条边缘。秤盘内部隐藏的挡水立边仍保留 Z=34.5，以维持原活动间隙关系；它完全位于秤盘覆盖范围内，不是外露显示台座。

名义秤盘下翻边底 Z=31.5，与外壳顶沿相差 1.5 mm。默认垫片下纯下移 0.8 mm 后，该竖直尺寸差为 0.7 mm；实际允许位移需结合限位、偏载、倾斜、公差再确定，不能仅靠此尺寸认定过载保护成立。显示座与隐藏挡水边之间新增连续固定平台，遮住内部电子件，不跨接活动秤盘。

## 屏幕与接线重新布置

上一版的 4 mm 下移限制来自 TFT 接线朝前且正对主板 J6 插座，**不是平顶壳体的固有限制**。本版将 TFT 模块在平面内转向 180°，把原朝前的接线区域移到后侧；保留完整的 22×4×6 mm 接头 / 线束包络，未缩小它来绕过检查。

相对最初齐平的 v0.4.2，前玻璃、TFT 与触摸件下移 9.8 mm：

- TFT PCB 底面 Z=24.7，J6 插座包络顶 Z=23.6，名义竖直净距 **1.1 mm**。
- TFT 后向接线包络为 X=-11..11、Y=-42.5..-38.5、Z=18.7..24.7。
- J6 仍在原位置，主板、电池、底架和 PCB 文件均未修改。
- TFT 外形及有效显示窗仍沿用此前的包络和居中假定；实际模块的接头位置、板背元件、线束弯曲和显示窗偏置需按实物确认。

装配时按后向接线安装屏幕，并在显示初始化中核对图像方向；必要时将显示旋转 180°。本轮交付为机械模型，未修改固件。触摸模块不随 TFT 转向，左右触摸键的位置维持原设计。

## 可调称重结构

上下整面垫片默认各 0.30 mm，单端建模范围 0.20–0.40 mm；四个限位间隙默认 0.60 mm，范围 0.40–0.80 mm。定位销、底部锁紧、塞尺入口、校准与调节流程见 [v0.4.2 说明](../v042/README.md)。其中旧版前玻璃与秤盘齐平的说明不适用于本版。

**这些范围不能任意组合到极限。** 补充检查发现，两端各 0.20 mm 垫片再配四处 0.80 mm 限位，会在刚性下压末端侵入原天线避让包络。输入检查现要求 `min(stop_gaps) ≤ 0.8 + (两端垫片总厚度 − 0.6)`，单位 mm；最薄组合的第一个限位必须不大于 0.60 mm。这只是纯下移时的几何上限，偏载倾斜和公差仍需额外留余量。

两端垫片组合改变秤盘高度时，前玻璃 / 塑料顶面保持固定 34.0 mm 距地高度，秤盘距地为 43.6–44.0 mm，突出量为 9.6–10.0 mm。原 0.60 mm 限位仍是建模初值，需要实测设定。
